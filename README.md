# PhonePe Pulse Data Visualization and Exploration

## Overview
An interactive Power BI dashboard exploring PhonePe Pulse transaction and user data across Indian states and quarters.

## Tools
- Power BI Desktop
- Power Query
- DAX

## Dashboard Features
- India map showing state-wise transaction amount
- State-wise transaction and registered-user charts
- Quarterly transaction trend
- KPI cards for transaction count, transaction amount, and registered users
- Filters for year, state, transaction type, quarter, and brand
- Year-over-year transaction amount growth

## Key Insights
- For 2022, the dashboard shows 39 billion transactions and a total transaction amount of 64.27T.
- Transaction amount YoY growth is 85.7% compared with 2021.
- Telangana has the highest transaction amount at 9.31T, followed by Maharashtra (7.85T) and Karnataka (7.70T).
- The quarterly transaction amount trend rises from Q1 to Q4 in 2022.
- In the available 2022 user data (Q1), Maharashtra leads with 48M, followed by Uttar Pradesh (39M) and Karnataka (31M).

## Data Note
The supplied aggregated user dataset has 2022 data only through Q1. Transaction amount is not the same as PhonePe revenue or profit.

## Dataset
PhonePe Pulse dataset supplied with the project.
